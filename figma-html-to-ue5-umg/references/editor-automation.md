# UE5 editor automation reference

Use this reference when the task asks for actual project assets instead of an implementation plan.

## Preferred structure

Keep generated UI under a scoped path such as `/Game/UI/<Feature>/`:

```text
/Game/UI/<Feature>/WBP_<Root>.uasset
/Game/UI/<Feature>/L_UI_<Feature>.umap       (optional preview map)
/Game/UI/<Feature>/Textures/T_UI_*.uasset
/Game/UI/<Feature>/Fonts/F_<Feature>.uasset
```

The Widget Blueprint should inherit from a UI-only `UUserWidget` base when runtime behavior is nontrivial. Put gameplay-independent state and request delegates in that base. A deterministic editor commandlet can construct the WidgetTree, CanvasPanelSlots, Brushes, TextBlocks, Images, Buttons, and `UWidgetAnimation` assets, then compile and save the Blueprint.

## Safe generation sequence

1. Compile the editor target before invoking the commandlet.
2. Check whether the destination asset exists. Rebuild only when the user requested replacement or the asset is clearly generated by this workflow; otherwise stop before overwriting.
3. Create/save source font and Texture2D assets before assigning them to widgets. Validate that each texture is a `Texture2D` and uses UI texture settings.
4. Create the Widget Blueprint and set its parent class. Build the widget tree with stable names. Use `bIsVariable` only for widgets accessed by runtime logic.
5. Create animations after all target widget names exist. Bind tracks to the actual WidgetTree objects and compile the Blueprint.
6. Create an optional blank preview map with a dedicated preview GameMode/PlayerController. Do not modify the project’s existing gameplay map or game mode merely to preview UI.
7. Instantiate the generated class in an editor world and run state checks. Save a report containing asset paths and counts.

## Assets

Inline SVG can be rasterized into transparent PNG masks. Use a white mask and tint it in UMG when the source icon changes color across states. Import with `TextureGroup_UI`, no mipmaps, clamp addressing, and alpha preserved. Keep the original source line/file in a manifest. Do not copy an external font or icon without a license path; if no legal font is available, use an existing project font and record the substitution.

## Commandlet verification

The commandlet should emit a machine-readable or plain-text report with:

```text
WidgetBlueprint: /Game/UI/<Feature>/WBP_<Root>
Widgets: <count>
Animations: <count>
UI state checks: PASS|FAIL
Preview map: <path or none>
```

Do not use `-nullrhi` for render-to-texture screenshots unless the renderer/resource path is known to support it. A null-RHI crash during capture does not invalidate a successfully saved WBP; report structural and interaction checks separately from visual capture.
